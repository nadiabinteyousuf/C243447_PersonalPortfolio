```text

│

│   └── profile.jpg
```

**File descriptions:**

- `index.html` — Contains the structure and content of the website.
- `style.css` — Controls the appearance, colors, layout, and responsive styling.
- `script.js` — Handles JavaScript interactions, such as the mobile navigation menu.
- `images/` — Stores images used on the website.
- `README.md` — Explains the project and how to access it.

## How the Website Works

### HTML – Structure

HTML defines the different sections of the portfolio, including the navigation bar, introduction, projects, skills, and contact information.

### CSS – Design

CSS styles the website and controls its layout, colors, typography, spacing, and responsiveness across different screen sizes.

### JavaScript – Interactivity

JavaScript adds interactive behavior to the website, such as opening and closing the navigation menu on smaller screens.

## Setup Instructions

### Step 1 – Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/nadiabinteyousuf/C243447_PersonalPortfolio.git
```

### Step 2 – Open the Project Folder

```bash
cd C243447_PersonalPortfolio
```

### Step 3 – Run the Website

Open the `index.html` file in your web browser.

You can also open the project in Visual Studio Code and use the Live Server extension if you have it installed.

No additional packages or backend server are required for this basic portfolio website.
